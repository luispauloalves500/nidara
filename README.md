# Nídara

Tubarão fóssil na Baía do Véu. Você nasce sem boca. O que come abre o próximo corpo. O site desta branch já está pronto para o GitHub Pages: `index.html` na raiz, sem servidor.

## Ligar o Pages (uma vez)

O jogo já está no repositório. Falta só publicar a branch:

1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Branch **main**, pasta **/ (root)**, e salve.

O endereço fica [luispauloalves500.github.io/nidara](https://luispauloalves500.github.io/nidara/). A primeira publicação leva cerca de um minuto.

## Jogar

- **W / S** acelera e recua. **A** vira à esquerda, **D** à direita.
- **R / F** sobe e desce o focinho. **Espaço** morde. **E** usa o poder. **Esc** pausa.
- No celular: alavanca, Morder, Poder, Subir e Descer.

Fique no berçário e atravesse o cardume. A sardinha entra no contato. Aos 90, 240 e 520 de carne o jogo oferece um enxerto. O terceiro acorda o Irmão Cego na fenda.

O dossiê dentro do jogo, e o `GDD.md`, são o documento de design.
