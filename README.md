# Nídara

Tubarão fóssil na Baía do Véu. Você nasce sem boca. O que come abre o próximo corpo. Feito em Three.js para GitHub Pages — esta pasta já é o site estático.

Abra o jogo: [luispauloalves500.github.io/nidara](https://luispauloalves500.github.io/nidara/)

## Jogar

- **W / S** acelera e recua. **A** vira à esquerda, **D** à direita.
- **R / F** sobe e desce o focinho. **Espaço** morde. **E** usa o poder. **Esc** pausa.
- No celular: alavanca, Morder, Poder, Subir e Descer.

Fique no berçário e passe por dentro do cardume. A sardinha entra no contato. Aos 90, 240 e 520 de carne o jogo oferece um enxerto. O terceiro acorda o Irmão Cego na fenda.

O dossiê dentro do jogo, e o arquivo `GDD.md`, são o documento de design.
